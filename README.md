# Chomptris: Python Edition
## What is this?
This is a **Python** port of the original **Chomptris**, which was written in **C**.
This is not meant to replace the original **Chomptris**.
## How to play
You can start the game via:
```bash
<Python interpreter> main.py
```
### Mechanics
All game mechanics are the same or nearly the same as the original,
with the main difference (if there's anything else) being the keybinds for restarting and exiting:
- CTRL+R -> F1  (Restart session)
- CTRL+Q -> F10 (Quit game)
## Help
As with the original, the help text explains all mechanics, controls, formulas, and more.
